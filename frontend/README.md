# ExoAtlas

React, TypeScript и Vite. 3D-сцена использует Three.js через React Three Fiber.

## Локальный запуск

1. Запустите FastAPI из проекта `exoplanet-backend`. Проверьте, что `http://127.0.0.1:8000/api/catalog` показывает успешный импорт.
2. В отдельном терминале из каталога фронтенда запустите:

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. В режиме разработки Vite проксирует `/api/*` на `http://127.0.0.1:8000`. Для другого порта или автономного демо создайте `.env.local` по образцу `.env.example`. `VITE_BACKEND` задаёт адрес API, а `VITE_USE_MOCK=true` включает заглушки.

## Данные

- Главная и «Топ-50» используют один снимок из `GET /api/ranking`. На главной показаны первые пять кандидатов из разных систем. Их движение на сцене условное.
- «Все экзопланеты» использует `GET /api/planets` для поиска и пагинации и `GET /api/planets/{id}` для карточки.

## Сборка

```sh
npm run build
```

Готовые файлы появятся в `dist`. При размещении сборки обслуживайте `/api/*` на том же домене через обратный прокси.
