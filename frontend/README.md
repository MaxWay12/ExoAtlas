# ExoAtlas

React, TypeScript и Vite. 3D-сцена использует Three.js через React Three Fiber.

## Локальный запуск

1. Запустите FastAPI из проекта `exoplanet-backend`. Проверьте, что `http://127.0.0.1:8000/api/catalog` показывает успешный импорт.
2. В отдельном терминале из каталога фронтенда запустите:

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. По умолчанию он проксирует `/api/*` на `http://127.0.0.1:8000`. Для другого адреса задайте `VITE_BACKEND` в `.env.local` по образцу `.env.example`. `VITE_USE_MOCK=true` включает демонстрационные данные 3D-сцен; рейтинг, графики и каталог обращаются к API.

## Данные

- Главная и «Топ-50» используют один снимок из `GET /api/ranking`. На главной показаны первые пять кандидатов и графики по списку рейтинга. В «Топ-50» фильтрация и сортировка работают по этому снимку.
- «Вселенная» использует `GET /api/systems` для карты и `GET /api/systems/{id}` для карточки системы. Данные о восьми планетах Солнечной системы хранятся в `src/galaxy/solarSystem.ts`.
- «Все экзопланеты» использует `GET /api/planets` для поиска, сортировки и пагинации и `GET /api/planets/{id}` для карточки.

## Сборка

```sh
npm run build
```

Готовые файлы появятся в `dist`. При размещении сборки обслуживайте `/api/*` на том же домене через обратный прокси.
