# ExoAtlas

ExoAtlas — интерактивный каталог экзопланет и рейтинг кандидатов по индексу жизнепригодности. Проект команды **JPEG** для **TulaHack-2026**. [Открыть ExoAtlas](https://exoatlas.ru/)

| Раздел | Возможности |
| --- | --- |
| [Главная](https://exoatlas.ru/#home) | 3D-сцена с первыми пятью кандидатами и графики распределения радиусов и равновесных температур. |
| [Вселенная](https://exoatlas.ru/#galaxy) | Интерактивная карта звёздных систем. Её можно перетаскивать и приближать до 10×, открывать системы и карточки планет. В центре находится Солнечная система с восемью планетами. Положение систем на спирали и размеры орбит на схемах условные. |
| [Топ-50](https://exoatlas.ru/#top) | До 50 кандидатов с фильтрами, сортировкой по заголовкам и разбором баллов. При сортировке исходное место планеты сохраняется. |
| [Все экзопланеты](https://exoatlas.ru/#catalog) | Поиск по планете или звезде, фильтры по физическим параметрам, карточки и сортировка всего результата перед пагинацией. |

## Данные и рейтинг

Данные поступают из таблицы `pscomppars` архива NASA через TAP. Планировщик обновляет каталог и пересчитывает рейтинг в **00:00 и 12:00 по Москве**. В разделе «Топ-50» отображаются время последней успешной загрузки NASA и время пересчёта.

В итоговом балле обитаемая зона даёт до **50** баллов, радиус — до **35**, плотность — до **15**. Пропуски уменьшают доступный вклад: вес отсутствующего фактора не переносится на другие. Карточка показывает происхождение параметров, границы зоны по модели Коппарапу и вклад каждого фактора.

## Локальный запуск

С установленным Docker Compose выполни из корня репозитория:

```sh
cd backend
docker compose up --build -d
docker compose logs importer
```

После завершения импорта открой [приложение](http://127.0.0.1:8000/), [страницу проверки](http://127.0.0.1:8000/check) или [Swagger](http://127.0.0.1:8000/docs).

Для работы над интерфейсом запусти `npm ci` и `npm run dev` в каталоге `frontend`. Vite проксирует запросы к локальному FastAPI. Перед обновлением сайта собери фронтенд через `npm run build` и перенеси содержимое `frontend/dist` в `backend/catalog/frontend`. Эта папка содержит сборку, которую FastAPI отдаёт на VPS.

Инструкции для разработки находятся в [README фронтенда](frontend/README.md) и [README бэкенда](backend/README.md).
